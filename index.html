Read-Only MCP App

Form Submission Validator

This app checks whether submitted form fields meet the required conditions before a form is submitted.

It helps ChatGPT, Codex workflows, and agent pipelines validate required form fields before creating tasks, preparing submissions, or passing data to downstream systems.

It does not submit forms, fill missing fields, rewrite form content, make submission decisions for users, call external systems, or store user data.

Privacy Terms Support Health

What It Does

  • Checks required fields against submitted fields.
  • Detects missing required fields.
  • Detects empty or null required field values.
  • Returns can_submit, missing_fields, invalid_fields, and errors in a fixed JSON structure.

Where It Fits

  • Form preparation workflows before submission.
  • Agent pipelines that need a deterministic validation step.
  • Task creation or application workflows that must verify required fields.
  • Read-only workflows that need stable validation without side effects.

What It Does Not Do

  • It does not submit forms.
  • It does not fill in missing information.
  • It does not rewrite user input.
  • It does not decide whether the user should submit.
  • It does not call external systems or external APIs.
  • It does not store request data or create user state.

MCP Endpoint

The MCP endpoint is POST /mcp. Health is available at GET /health.
